# 📖 Sobre o Projeto

A **Agência Vanzoff** é uma plataforma Full Stack desenvolvida para representar digitalmente a agência, oferecendo uma experiência moderna, responsiva e focada em conversão.

O projeto integra:

- Landing Page institucional
- Blog dinâmico
- Painel administrativo
- Sistema de gerenciamento de conteúdo
- SEO otimizado
- Captação de leads
- Integração com serviços externos

O objetivo da plataforma é unir **design moderno**, **alta performance** e **estratégias digitais** para fortalecer marcas e gerar resultados reais.

# ⚙️ Como Executar o Projeto

 # 🔧 Back-end (Spring Boot)
   **Pré-requisitos** 
- Java JDK 17
- Maven

**Instalação**
```bash

# Clone o repositório
git clone https://github.com/VanzoffDEV/Nosso-Site.git

# Entre na pasta do servidor
cd server

# Instale as dependências
mvn clean install

# Execute a aplicação
mvn spring-boot:run
```
**Variáveis de Ambiente**
 ```bash
DB_URL=
DB_USERNAME=
DB_PASSWORD=

CLOUDINARY_CLOUD_NAME=
CLOUDINARY_API_KEY=
CLOUDINARY_API_SECRET=
```
# 🎨 Front-end (React + Vite)
**Pré-requisitos**
- Node.js

  **Instalação**
 ```bash
  # Entre na pasta do cliente
    cd client

 # Instale as dependências
   npm install

 # Rode o projeto
   npm run dev
  ```
